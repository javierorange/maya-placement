# Placement source websites

Living list of boards and career pages to search for **6–12 month student placements**. The weekly agent **adds new URLs here** as well as individual offers in `placements.csv`.

Access:

- **Public** — agent may fetch listing pages and search results.
- **Maya-manual** — login required (Bath student account or other personal login). List the URL; do not log in, scrape behind auth, or store credentials.

## Company career pages

The weekly run should add **direct employer career URLs** here when it finds a 6–12 month student programme (FMCG, consulting, finance, luxury, tech GTM). Do not add graduate-only pages.

## How to add a source

Append a row with name, listing URL (not a homepage if a placements filter exists), region, Public vs Maya-manual, and one-line why. Skip duplicates of the same board.
